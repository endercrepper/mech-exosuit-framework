# Design Document

Questo documento è la **baseline di design** per la mod [Mod Name].

## File principale

- **`ModName_Design_Document.pdf`** (70 pagine, ~1.3 MB) — design document v0.1 completo

## Indice dei contenuti

1. **Concept & Vision** — riassunto esecutivo, 3 pilastri di design, posizionamento competitivo
2. **Architettura Tecnica** — diagramma classi C#, scheletri di 5 classi + SubcoreInfoBridge
3. **Schema Defs XML** — 6 snippet XML completi + struttura directory progetto
4. **Sistema di Danno & Morte** — 2 flow diagram, formula di recupero deterministica
5. **Bay Ibrida & UI** — schema 4 funzioni, struttura ITab 5 sezioni, workflow gestazione
6. **Batteria & Bandwidth** — capacità per tier, degradazione cumulativa, sinergia
7. **Integrazione SubcoreInfo & CE** — bridge via reflection, 4 punti di chiamata, matrice compatibilità
8. **Bilanciamento Patriot** — 8 tabelle complete (stat, HP, battery, costi, jobs, skill, formula)
9. **Albero Tecnologico** — albero visuale, 5 nodi ricerca con techprints
10. **Roadmap MVP** — 8 milestone (M0→M7) con stime ore e risk register
11. **Checklist Implementazione** — setup progetto, API signatures, pattern di testing, pitfall comuni
12. **Glossario** — 36 termini con tipo (vanilla/mod/ModName) e definizione
